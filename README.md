# Prompt Engineering – Task 3

This repository contains the submission for Task 3 of the **Future Interns** Prompt Engineering Track.

## Overview

This task involved:
- Creating clear and concise prompts
- Applying them to two different AI models: **Claude 3.5 Sonnet** and **GPT-4o mini**
- Comparing the responses against the expected outcomes
- Drawing conclusions on performance, creativity, and contextual understanding
